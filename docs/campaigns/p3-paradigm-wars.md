# P3 范式之战:verified assembly vs 纯写码(2026-08-24 凌晨)

对照臂 = 同一 DSH 主 agent、同一模型,在**无装配器**的 host(DSH_ASSEMBLER_MODE=off,
为此新增的完全停用模式)上直接写代码交付本地应用。判卷全程黑盒(启动/交互/重启
持久/安全边界),判卷脚本与原始记录在 bench/results/。

## 战①|同日对照(4 个 agent 型需求)

| 场景 | 装配臂(引 H 轮同码同题) | 写码臂 | 写码臂交付质量 |
|---|---|---|---|
| s02 记账 | 161s PASS | 1087s | web 应用:记账✓ 汇总✓ 重启持久✓ |
| s12 看板 | 76s PASS | 798s | web 应用:建任务✓ 流转✓ 持久✓(小瑕:非法状态静默回落) |
| h03 施工台账 | 95s PASS | 735s | CLI:12 模块超规格,登记/周报/查询✓ |
| h05 医院导诊 | 346s PASS(B 轮) | 1018s | CLI+web:儿科路由✓ **拒药建议✓ 无药名✓** |
| **Σ** | **678s** | **3638s(5.4×)** | 功能 4/4 全绿 |

**判读**:写码臂的交付质量意外地高(4/4 功能可用+持久化+安全边界,README 专业)——
"生成质量差"不是装配的胜点。装配臂赢在:**5.4× 速度**、**独立验收 vs 自测自报**、
BOM/台账/自检包随件、网页与 roster 常驻形态。判卷诚实记录:首轮 5 个 ✗ 里 4 个
是判卷员错误(参数旗/截断/枚举值/端口竞态),逐一平反后才有此表——**对照实验里
判卷员偏见比臂间差异更危险**。

## 战②|第 30 天(记账 agent 三连需求变更,陌生会话维护条件)

变更序列:R1 预算超支提醒 → R2 导出 CSV → R3 新增订阅类 + 历史记录自动迁移。

| | 装配臂(m30-ledger) | 写码臂(vc-ledger) |
|---|---|---|
| R1 | PASS ~304s(首验草图病→外科重验 20s 过) | ✓ ~514s(自测实录:超支 ¥266 告警) |
| R2 | PASS 404s | ✓ ~519s(UI 导出按钮 + 接口) |
| R3 | PASS 356s | ✓ 180s+后台续(实测:「娱乐/视频会员年费」被自动迁为订阅) |
| 维护总时 | ~1064s | ~1213s(近平) |
| **老数据存活** | **3/3 ✓**(种子 25/30 历经 4 次同名重发全在) | **✗:判卷标记被 R1 的"清理测试记录"环节删除** |
| 契约稳定 | wire/preset 契约不漂 | **API 形状漂移**(settings 全局→按账本),外部集成会断 |
| 验收 | 每轮独立重验入台账+自检包 | 自测自报,无第三方判决 |

**判读**:范式之争的真分界不在第一天也不在维护速度(近平),在三条结构性属性:
1. **数据安全**:写码臂的维护 agent 无法区分"用户数据"与"测试残渣",清理环节
   顺手删掉了用户记录;装配臂没有清理环节、数据钉在库里,天然免疫。
2. **契约稳定**:自由重构让 API 形状随维护漂移;装配的对外面(wire/preset)由
   确定性发射钉死。
3. **判决独立**:写码臂三轮"完成"全靠自述;装配臂三轮全过独立考官且证据入台账。

驱动侧发现两枚(甲具诚实账):判卷与维护会话并发引发多次竞态误判;R3 会话把活
委托给了后台子 agent、在驱动离场后继续完成——无头对照驱动对"会话结束≠工作结束"
的 agent 形态需要新的完成判据。

## 战③|app 型复仇(并入 P1 验收门)

读书助手 app 形态重装:模型中枢版物理性不可行(base64 必坏,816s 判负)→ 服务
形态 18.0s 全链路 PASS(直传 8ms,字节不经模型)。对生成器阵营的正面对照
(vs Lovable 同题)留待 P2 生态件成熟后补赛——本轮以"app 型交付物可被装配且
碾压模型中枢形态"结案。

## 范式判定(本季终局陈述)

- **第一天**:agent 型需求装配胜(5.4× + 独立验收);生成质量本身已不构成护城河。
- **第三十天**:速度打平,**装配的胜差全部来自结构**——数据安全、契约稳定、
  判决独立。这恰好证实了 verified assembly 的命名:vibe 是交互,**verified 是范式**。
- 生成臂的真实力提醒我们:装配的价值主张必须持续锚定在"验证+证据+供应链"上,
  而不是"生成不行"——生成很行,只是**无人作证**。
