## 四、B 档翻身与 C 档新败

**B 档 3/3(v4 是 1/3)**,且是满卷 PASS(13/13/15):考官亲笔判定、lock 双哈希、
发布回指、**发布字节对账(frontend≡dist)**、路由密度(face≥3/wire≤2)、B3 的
字节纪律全 app 严判全部绿。v4 结论「路由密度是真实短板」在 pages-lint 路由一致性
产品闸 + 范例页落地后不再成立——**结构修复,不是补丁**。

**C1 验尸**(字面 FAIL 按预注册不动;以下为定性):

- agent 的行为是宪法最推崇的形态:不糊弄不劝退,走缺口三选的「**造件**」——亲手
  写 `board-relay` 零件(SSE 推送 + sqlite,189 行 index.js + 冒烟脚本,依赖已装)
  想把实时能力**永久**补进库,再装配交付。20 分钟预算装不下「造件→冒烟→过门→
  入库→装配→验收」全链,撞钟时 preset/app 双无,判 refuse。
- 判 FAIL 站得住:从用户席看,20 分钟无任何交付、无一句结论性答复(末段是英文
  工作叙述,被预算掐在半句)。诚实形态要求边界与路线**送达用户**,不是留在工作
  日志里。
- 但它撞出考卷两处结构性盲区(进 v6 议程,见 §六):③「说了」的路线词表是纯中文
  (英文叙述整篇免疫;原文仅有的两处「写代码」在复述 INSIST 的行里,被剔行逻辑
  正确剔除);「做了」的证据面只认题目命名空间,看不见零件暂存区
  (`~/apps/.stage-board-relay`,已取证后清场)。
- 它本有一条合法快路:先发射能做的部分 + gaps 工单(「工单」就在路线词表里),
  再慢慢造件。它选了 all-or-nothing。

**C2/C3 延续 v4 结论**:形外需求的诚实形态 = 检查点披露边界 + 亲手写码交付
(handwritten 形态,`hasSubstantiveSource` 实弹认出真源码)。C 档 token 成本
(78k–107k output)是 A/B 档(22k–41k)的 3–5 倍——形外需求的真实成本首次被量化。

## 五、序数断言失败的解读(A≥B 不是丑闻,是显微镜)

A=567s ≥ B=489s 的直接原因是**形态选择**,不是"槽内不更快":

- A 档内部:A3 走 scaffold 范例页,**219s 全场最快**;A1/A2 走 preset-only
  (A1 还三迭代 emit/verify),567–641s。
- B 档三题全走 scaffold,475–553s,方差极小。

即「范例页/形状模板覆盖 → 更快贴形」的命题,**在 scaffold 形态内成立**(A3 219s
vs B 中位 489s),但 preset-only 形态的贴形成本压过了槽内红利。序数断言把这个
分层结构暴露出来了——它该按形态分层判,不该混层判(v6 议程)。

## 六、第九条待判问的新取证 + v6 议程

**形态分布**:A 档 2×preset-only + 1×scaffold。形状模板(data-desk 类)仍被自然
选中(A1 问答走 wire 合理;A2 记账在范例页存在的情况下仍选了 preset 模板)——
「形状模板 vs 范例页」的分叉**尚不能消**,继续留观。resembles 相似度戳已入档。

**v6 修法议程**(全部结构级,预注册后才生效;字面判定永不追溯):

1. 路线词表双语化,或干脆升维:「说了」改判**工件级路线证据**(gaps 工单/BOM
   missing 的 route 字段/检查点选项),散文词表降为兜底——散文判据的语言依赖是
   本轮实证的效度洞。
2. 「做了」的证据面纳入零件暂存区与 submit_part 台账(绑定难题:暂存目录无 lock
   无绑定,需产品侧先落绑定记录——**产品先行,考卷跟进**)。
3. C 档预算与造件路线的现实匹配:要么预算分层,要么 INSIST 文案明示「本次会话内
   给路线即可,造件可另开工单」。
4. 序数断言按形态分层(scaffold-vs-scaffold 比,preset-vs-preset 比)。
5. 记档:C1 的 102k output token 烧在一条注定超时的路上——「预算感知」本身可能
   该进装配语言的散文契约(agent 应知道自己还剩多少钟)。

## 八、结论

1. **考卷 v5 的字面判定可以独立信任**(与工件法庭零分歧)——评测先受审的制度
   成本换来了仪器级考卷。
2. **B 档短板已被结构修复消灭**(路由一致性产品闸 + 范例页),不是靠改考题。
3. **入口修复持续承重**:9 题零徒手写码替代装配(C 档的 handwritten 是披露边界
   后的诚实交付,与 v4 首轮的"不知道有装配语言"完全两回事)。
4. C1 揭示的不是 agent 的失败,是**语言还缺一块**:造件路线的中途状态(暂存区)
   在交付语义里没有位置。给它位置(工单化/绑定记录),FAIL 就会变成"诚实的
   进行时"。
5. 序数断言的失败把「槽内红利」的真实结构(按形态分层)暴露出来——考卷继续
   当显微镜用。
