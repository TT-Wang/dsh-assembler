## 一、A股行情 —— 终判:采 `stock-sdk`

**造的底牌(全实测通,决策地基)**:腾讯 `qt.gtimg.cn`(零鉴权,GBK 文本,268ms)、
新浪 `hq.sinajs.cn`(仅需 Referer 头,不带 403 实锤)、东财 `push2/push2his`
(零鉴权 JSON,57–194ms,实时/K线/资金流全通)。三家现价互相印证(茅台 1302.80,
2026-08-26 收盘)。零凭证零费用国内直达,三家互备,协议十年存活。

**采:`stock-sdk` 2.4.2**(发布于侦察前 8 天,47 版,月下载 9,864;GitHub 1,899 星,
ISC,**零依赖**)。侦察兵已独立实探:`node cli.js mcp` 起服,listTools 回 **26 工具**
(A/港/美行情、K线含复权、分钟线、技术指标、筹码、板块概念、个股资金流、北向、
涨停池、龙虎榜、交易日、模糊搜索),真调 `get_a_share_quotes {codes:['600519']}`
回五档盘口完整 JSON。报错可行动。上游与实测三家一致 + 雪球/东财镜像。

**两根刺(有解)**:
1. bin 裸跑只打印 help,MCP 要 `cli.js mcp` 子命令——adopt 门首例带参启动件。
   修法定为 **adopt 加 `--bin-args`**(结构扩展,子命令启动是真实类目;包装入口
   会把「采」的出处链弄脏成半个「转」)。
2. `assets.linkdiary.cn`(作者自建 CDN)仅承载股票代码表静态 JSON,非遥测;
   行情不依赖它,挂了只坏按名搜索。入 BOM 记已知第三方静态依赖。

**验收形状**:adopt 独立实探 + `--probe get_a_share_quotes:{"codes":["600519"]}`
断言回价且 prevClose>0;再打 `is_trading_day`(离线日历,不吃上游波动)。零凭证件。

**否决**:Tushare 全系(token+积分门槛,免费市场里引入付费墙);
`@wbavon/china-market-data`(无 bin,过不了门);单人单版爱好者包(a-share-mcp
形状尚可但无 repo 9 天大,记作备胎不采)。

## 二、快递物流 —— 终判:造(快递鸟薄壳),采件全被凭证/费用卡脖子

**结构性事实:合法快递查询不存在零凭证上游。** npm 全部快递 MCP 拆开只有两个
后端:快递100 或 17track,且免费层集体塌方:

| 上游 | 免费层 | 判 |
|---|---|---|
| **快递鸟** | **500 单/天可持续**,个人可注册 | 唯一能长期免费的合法门 → 造 |
| 17track | 2026-01 起免费层改一次性 200 单(试用装不是水管) | 否决作主线 |
| 快递100 | 一次性试用 100 单,企业账号向 | 客户带企业 key 时再采官方件 |

**采件核验记录**:`parcel-tracking-mcp`(17track 后端)凭证契约脸达标(惰性读 key,
报错点名 env 给注册 URL)——采件里形状最好,但上游免费层已死;
`@kuaidi100-mcp/...` 官方件没 key 启动即 exit(1),adopt 独立实探都过不去。
**转已死**:快递库全部陈化(2017–2023),快递鸟签名十几行不如手写。

**造的形状**:零件 `express-track`,壳约 60 行(MD5+Base64 签名 + POST);工具面
`query-express {carrier, trackingNo, phone?}` + `detect-carrier`(免费层含否注册后验)。
**凭证契约脸先行交付**(speech-io ASR 先例):没配 `KDNIAO_EBUSINESS_ID`/
`KDNIAO_API_KEY` 时起得来、listTools 通、调用回可行动错误;真单号模型脸进
「等用户」清单(需注册快递鸟)。

**否决:kuaidi100 免鉴权网页灰色端口**——实测确实吐真轨迹,但无契约、有验证码
风控前科、单号识别端口已加 key 门(701 实测);识别断了灰色路线只剩用户自报承运商。
不碰。

## 三、通用采购工程备忘(归阶段 2 闸门手术)

1. **adopt 门凭证件盲区**:惰性读 key 的件过 listTools 但 --probe 必挂;启动即
   exit 的件连门都进不去。需要「凭证契约模式」:listTools 通过 + 真调回可行动
   错误 = 收(与 verify-faces 第三张脸对齐)。
2. **adopt 门子命令盲区**:bin 需带参数的采件(stock-sdk 首例)→ `--bin-args`。
3. 官方 MCP registry 对这两件零结果,npm 就是全部矿面。
